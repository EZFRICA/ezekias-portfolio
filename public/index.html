I design how AI agents remember, and how they evolve.

Ezekias Bokove, Applied AI Engineer and Google Developer Expert for Google Cloud.

The Agent Processor Unit is my open architecture for agent memory. It runs memory the way a processor does: a cache in RAM, a page table, paging to disk, and a scheduler that answers first and writes later. Every number behind it is measured on a real system.
